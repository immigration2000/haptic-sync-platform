## 왜 (제보)

> "내 PC 에서는 잘되는데 다른 컴퓨터에서는 카메라가 화면에 안 띄워주네"

기존 코드는 **실패 원인을 전부 조용히 삼켰다.** 그래서 원격으로 좁힐 수가 없었다.

| 조용히 죽던 지점 | 결과 |
|---|---|
| `getUserMedia` 거부 → `catch` 에서 `'카메라 권한이 없습니다'` 한 줄 | 권한 거부 / 다른 앱 점유 / 장치 없음을 **구분 불가** |
| `video.play().catch(()=>{})` | 자동재생 차단이면 **그냥 검은 화면**, 아무 표시 없음 |
| `getUserMedia({video:true})` — 장치 지정 없음 | 카메라가 여러 개면 브라우저 기본값. **가상캠(OBS)·IR 캠**이 잡히면 검은 화면 |
| `http://192.168.x` 접속 | `navigator.mediaDevices` 자체가 없어 **TypeError** (보안 컨텍스트 아님) |

## 넣은 것

### `public/js/core/camera.js` (신규) — 선택·열기·붙이기·진단을 한 곳에

- **보안 컨텍스트를 먼저 본다.** `https`/`localhost` 가 아니면 그 사실과 **현재 주소**를 적는다
  → LAN http 로 열었을 때 원인이 바로 보인다
- 오류 이름을 **사용자가 할 수 있는 조치**로 번역
  (`NotAllowedError` → 주소창 자물쇠 / `NotReadableError` → Zoom·OBS 종료 / `NotFoundError` → 목록에서 다른 카메라)
- **저장된 `deviceId` 가 그 PC 에 없으면 '자동' 으로 한 번 더 시도.** 선택은 `localStorage`
  (`pulse_cam_device`) 라서 다른 PC 에서는 존재하지 않는 값일 수 있다 — 그대로 실패시키면 안 된다
- `attach()` — `muted`·`playsInline`·`autoplay` 를 보장하고 **`play()` 결과를 보고**한다.
  차단되면 "화면을 한 번 클릭하면 보입니다" + 클릭 1회 폴백
- `describe()` — 라벨·해상도·fps·트랙 상태를 한 줄로 (`로지텍 C920 · 1280x720 @30 · live`)
- 콘솔에서 `PulseCamera.report()` 로 장치 목록·보안컨텍스트·저장된 선택을 덤프

## 2차 — ⚙ 설정 버튼으로 장치 선택 모음 (`main 920f64d`)

인라인 카메라 선택을 **설정 버튼 하나**로 모으고, 통화 화면에 없던 마이크·스피커 선택을 같이 넣었다.

| 설정 패널 (⚙) | 비고 |
|---|---|
| 📷 카메라 | 바꾸면 스트림 재연결 |
| 🎤 마이크 | 통화 중이면 `replaceTrack` 으로 교체(재협상 없이) · **음소거 상태 유지** |
| 🔊 소리 출력 | 수신 음성 요소 전부에 `setSinkId`. 미지원 브라우저면 그 사실을 표시 |
| 진단 줄 | 실패 사유·현재 스트림 요약 |

- **버튼은 연결 전에도 보인다** — 통화 시작 전에 장치를 고를 수 있어야 한다.
  통화 전 변경은 `저장됨 — 통화 시작 때 적용됩니다` 로 안내한다(조용히 무시하지 않는다).
- **열 때마다 목록을 다시 채우고**, `devicechange` 이벤트로도 갱신한다 (방금 꽂았을 수 있다).
- 보안 컨텍스트가 아니면(LAN http) 패널을 **자동으로 펼쳐** 사유를 바로 보여준다.
- 수신 음성 요소를 이제 들고 있는다 — 예전에는 `new Audio()` 를 버려서 **출력 장치를 바꿀 방법이 없었다.**

### ⚠ 함께 고친 잠재 버그 — 두 번째 장치 교체가 조용히 실패

simple-peer 는 추가된 스트림을 `(stream.id, track.id)` 로 기억한다.
장치를 바꿀 때 `micStream = newStream` 처럼 **스트림 객체를 교체하면** 다음 번
`replaceTrack(old, new, micStream)` 이 "never added" 로 **조용히 실패**한다 —
즉 **두 번째 마이크 변경부터 상대에게 반영되지 않는다.**

→ `PulseCamera.swapTrack(stream, oldTrack, newTrack)` 로 통일: 스트림은 그대로 두고 트랙만 갈아끼운다.
**BJ 콘솔(1:다수)에도 같은 버그가 있어서 함께 고쳤다** (`devInputSel` 변경 경로).

### camera.js 일반화

`fillKindSelect(sel, kind, key, onChange)` / `openMic()` / `applySink()` / `swapTrack()` 추가.
카메라용 `fillSelect()` 는 그 위에 얇게 얹었다 — 마이크·스피커도 같은 규칙(저장 복원,
