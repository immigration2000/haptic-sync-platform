## 기능 — 영상 속도 조절 · 볼륨 조절 (요청: 민수)

영상 아래 한 줄에 두 컨트롤을 뒀다. **VR 재투영 화면과 일반 영상이 같은 줄을 공유한다.**

| 왜 각각 필요했나 |
|---|
| **일반 영상** — `<video controls>` 라 볼륨은 네이티브에 있지만 **속도는 우클릭 메뉴에 숨어 있다** |
| **VR 재투영** — 캔버스를 보여주고 자체 컨트롤바(`#vr-controls`)를 쓰므로 **둘 다 없었다** |

- 속도: 0.5 / 0.75 / 1(원본) / 1.25 / 1.5 / 2배
- 볼륨: 0~100% 슬라이더 + 현재값 표시
- 선택값은 `localStorage` (`pulse_player_rate`, `pulse_player_vol`)에 남는다
- `loadedmetadata`(src 교체·되감기) 뒤에도 배속을 다시 적용한다 — 안 하면 1배속으로 돌아간다

### 음소거 처리 — 로드 시점에 풀지 않는다

영상은 자동재생 정책 때문에 `muted` 로 시작한다. **로드 시점에 코드가 스스로 음소거를 풀면
브라우저가 재생을 멈출 수 있다.** 그래서 해제는 **사용자가 볼륨 슬라이더를 움직였을 때만** 한다.
그 전까지는 `🔇 음소거 — 볼륨을 올리면 소리가 납니다` 안내를 띄운다.

## ⚠ 엔진 연동 — interp 를 배속으로 나눈다 (이게 핵심)

`interp`(이동시간)는 **스크립트 시간 간격**(`next.at - cur.at`)에서 뽑는다.
2배속으로 틀면 키프레임은 절반 시간에 지나가는데 기기에게는 원래 이동시간을 주게 되어
**기기가 영상보다 뒤처진다.** 그래서 엔진에서 나눈다:

```js
const rate = this.video.playbackRate > 0 ? this.video.playbackRate : 1;
const interp = Math.max(1, Math.round((next.at - cur.at) / rate));
```

`playbackRate` 가 없는 클럭(1:다수 방송이 넘기는 심)은 **1배속 취급** — 기존 동작 보존.
`rate` 가 0 이어도 1 로 떨어뜨린다(0 으로 나누지 않는다).
